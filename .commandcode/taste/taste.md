# Taste

## Workflow
- Prefers that completed changes be committed and pushed to the remote (e.g. `origin/main`) rather than left unstaged; explicitly asks for "commit and push" once a feature is verified and done. Confidence: 0.75
- Prefers validating features end-to-end against realistic simulated infrastructure — e.g., multiple dockerized OPC UA sim servers exposing real tag nodes — rather than mocked or in-app data alone. Applies both to reproducing reported behavior and to confirming design/capability claims: when asking "does X work?", the user explicitly requests a live test ("can you test it") rather than accepting reasoning from code alone. Confidence: 0.65

## Dashboard UX
- Prefers at-a-glance, consolidated visualizations for verifying live data flows over scanning raw tables row by row — e.g., explicitly requested an "Interlink Flow" panel in Live Values showing provider→consumer value pairs side by side with status pills, "instead [of] see one by one on Live Values". Followed up again when the flat link list made fan-out hard to read ("polish the ui/ux because we hard to see for multiple consumer from one provider"). When a feature spans multiple related items, surface their relationships (paired values, status, direction) in one view. Confidence: 0.7
- Dislikes flat lists that repeat the same entity once per relationship (e.g., the provider repeated on every link row): relationships like one-provider→N-consumers become invisible. Prefers hierarchical/tree grouping instead — the shared entity shown once as a parent row with related items nested beneath (connector lines, fan-out badge like "⇄ 3"), so relationship structure is obvious at a glance. Confidence: 0.6
- When splitting related views apart, prefers sub-tab switchers within the existing page (e.g., "Live Values" | "Interlink Flow" sub-tabs on ops/values) over adding new sidebar/top-level navigation entries — keeps related functionality grouped under one route. Chose the sub-tab option when offered alternatives (own sidebar tab, moving into the Interlinks page). Confidence: 0.5
