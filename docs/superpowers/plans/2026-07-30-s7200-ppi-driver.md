**Address model:**

```csharp
public enum S7Area { Inputs, Outputs, Flags, V }

public sealed record S7Address(
    S7Area Area,
    int ByteOffset,
    int SizeBytes,      // 1, 2, or 4 for sized forms; 1 for bit forms (bit select)
    int? BitIndex,      // 0-7 when bit form
    string Canonical);

public static class S7AddressParser
{
    public static bool TryParse(string? input, out S7Address address, out string error);
    public static string Canonicalize(string input); // throws or returns canonical if valid
}
```

**Parse rules:**
- Case-insensitive input; canonical uppercase area letters (`I0.0`, `VW100`).
- Bit: `I<byte>.<bit>`, `Q…`, `M…` — bit 0–7.
- Sized: `IB/IW/ID`, `QB/QW/QD`, `MB/MW/MD`, `VB/VW/VD` + decimal offset.
- V → `S7Area.V` (DB1 at protocol layer later).
- Reject empty, unknown prefix, bad bit, non-decimal offsets.

**Client behavior (mirror MelsecA3nClient):**
- Production ctor builds `SerialS7Transport`; test ctor injects `IS7Transport`.
- `SemaphoreSlim` single-flight.
- `ConnectAsync`: open + PPI connect/probe (small V or Flags read).
- `ReadAsync`: parse `ItemId`, batch consecutive same-area byte spans, retries, `BridgeValue` Good/Bad.
- `WriteAsync`: sized/bit writes; return false on failure (no throw for normal PLC NAK).
- `TryGetTagMetadata`: VT_BOOL for bits; VT_I2/I4-ish for W/D; I default access read-oriented; Q/M/V RW.
- V area → protocol DB=1.
- Soft batch cap ~64–222 bytes (constant; tune with fixtures).
